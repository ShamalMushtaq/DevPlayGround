# DevPlayGround 🚀

An advanced in-browser frontend development environment and project manager engineered for real-time code rendering, local data persistence, and efficient project management.

## ✨ Features
- **Live Workspace:** Real-time iframe rendering for HTML, CSS, and JavaScript.
- **Project Management:** Save, load, update, and delete multiple projects locally using `localStorage`.
- **Theme Switcher:** Seamless toggle between dark and light UI themes.
- **Shareable Links:** Generate and share base64 encoded code links instantly.

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
- FontAwesome Icons
- Google Fonts (Inter & Fira Code)
